# Project Operating Instructions

This file records the operational requirements supplied for this research project.

- Maintain a detailed research plan and follow it unless the plan itself is explicitly revised.
- Log errors and material methodology changes in the repository.
- Update research-phase status after meaningful steps.
- Keep README links current.
- Separate phases into branches.
- Use Python/Rust and GitHub Actions for reproducible research workflows where practical.
- Cache important market data rather than downloading it on every workflow run.
- Search broadly for market data and research inputs, including exchange sources and reputable open datasets.
- Model transaction costs, slippage and brokerage; use Paytm Money's current schedule for the broker-specific cost case when verified.
- For market/trading research, consider relevant global/NSE/BSE inefficiencies, options, DII/FII, regime/sentiment, volatility, benchmark indices, corporate actions and news where applicable to the research question.
- Produce a structured research manuscript with tables, figures, appendices and supplements at the end of the planned phases.

Note: conversation history and hidden chain-of-thought are not written to the repository. The repository records the user's research requirements, auditable decisions, results, errors and source-derived methodology instead.
